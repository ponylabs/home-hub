# 接入小米 / 米家设备

本指南适用于个人家庭通过 Home Assistant 的官方 Xiaomi Home 集成接入设备。栖居负责页面、场景、AI 和操作记录；Home Assistant 负责米家授权与设备通信，需要持续运行。当前尚未使用真实米家账号或硬件联调。

## 准备中枢

1. 在电脑、NAS 或家庭服务器上安装并运行 [Home Assistant](https://www.home-assistant.io/installation/)，确保栖居服务端能访问它。两者可以部署在同一台机器上。
2. 按[小米官方安装说明](https://github.com/XiaoMi/ha_xiaomi_home/blob/main/doc/README_zh.md)安装 Xiaomi Home 集成。使用该集成时遵守其[许可与使用范围](https://github.com/XiaoMi/ha_xiaomi_home/blob/main/LICENSE.md)。本项目不分发或嵌入这份集成代码。
3. 在 Home Assistant 的“设置 → 设备与服务”添加 Xiaomi Home，通过其登录流程授权米家账号。选择与米家 App 一致的地区和家庭，先确认目标设备能在 Home Assistant 内控制。
4. 在 Home Assistant 管理员个人资料的安全页面创建长期访问令牌。设备发现需要读取集成和设备注册信息，非管理员令牌会被拒绝。

不要将 Home Assistant 自带的旧 xiaomi_miio 集成或社区 Xiaomi Miot 集成误认为官方 xiaomi_home。专用入口按官方集成来源筛选；其他集成中的受支持实体可用栖居的通用 Home Assistant 入口接入。

## 配置栖居并导入

在仓库根目录创建 .env（已有文件直接编辑），填写真实地址和令牌：

```dotenv
HA_URL=http://homeassistant.local:8123
HA_TOKEN=你的管理员长期访问令牌
```

Docker 中的 localhost 指向容器本身，HA_URL 应填写栖居运行环境可以访问的中枢地址。如果 homeassistant.local 无法解析，使用中枢的局域网地址。

重启栖居后打开“接入与模型 → 小米 / 米家”，或“接入设备 → 小米 / 米家”：

1. 点击“发现小米设备”，检查可接入项目及暂不支持的项目。发现只读取数据，不写入栖居设备列表，也不开关设备。
2. 勾选需要的项目，点击“接入所选设备”。每批最多 100 项；同一实体重复接入会更新而不会创建副本。提交时会重新检查选择，若设备已移除或不再受支持，整批拒绝并要求重新发现。
3. 在“所有设备”中查看卡片，或通过房间导航筛选。在设备详情中可查看型号并调整房间。
4. 手动操作确认后，可保存场景，或在家居助手输入明确指令，例如“关闭米家阅读灯”（需替换为实际设备名）。自然语言理解仍需按[开发说明](../development.md)配置模型。

首次接入会读取 Home Assistant 中的房间；未分配时显示“未分配”。栖居中的手动房间设置在同步后保留。一个物理设备可能提供多个独立实体，例如温度与湿度分别显示，页面计数按这些项目计算。

## 支持范围与同步

当前支持灯光、空调、窗帘、开关和只读传感器；具体控件以 Home Assistant 实体公开的能力为准。空调按摄氏度使用，请将中枢温度单位设为摄氏度。风扇、净化器、扫地机器人、门锁、摄像头、按钮及模式选择等尚未接入栖居的统一模型，发现时列为暂不支持。这里的支持范围不代表小米官方集成覆盖所有品牌、型号和协议。

“同步已接入”只更新已选择的小米项目，不会自动导入新增设备。设备消失或中枢连接失败后，已接入小米项目显示离线，场景与本地房间信息仍保留；恢复连接后再次同步。新增项目使用“发现小米设备”再选择。

通用 Home Assistant 的“同步所有设备”会导入该中枢全部受支持实体，范围更广。网页自动刷新的是栖居快照；米家 App 中的操作需要手动同步后才能反映。栖居控制后会回读结果，目标状态尚未到达则记录“待确认”，不会自动重发。

没有小米中枢或相应本地能力时，官方集成可能通过小米云完成控制；Home Assistant 本身不保证离线控制。具体设备、地区与本地通信条件以[小米官方说明](https://github.com/XiaoMi/ha_xiaomi_home/blob/main/doc/README_zh.md)为准。

## 排查连接

| 页面情况 | 检查与恢复 |
| --- | --- |
| 尚未配置家庭中枢 | 同时填写 HA_URL 和 HA_TOKEN，并重启栖居进程 |
| 无法连接 Home Assistant | 核对地址、端口、DNS、容器网络及中枢运行状态 |
| 令牌失效 | 在 Home Assistant 创建有效令牌，替换服务端配置并重启 |
| 提示需要管理员令牌 | 设备发现调用管理员级只读模板接口，使用管理员长期令牌 |
| 未发现小米设备 | 检查官方集成已加载、米家授权、地区、家庭及实体是否启用 |
| 所选设备已变化 | 重新发现，核对当前列表后再选择导入 |
| 设备离线或控制待确认 | 先在 Home Assistant 检查设备，再回栖居同步；不要连续重复下发 |

令牌只存放在服务端 .env，不发送到浏览器或模型。服务端调用依据 Home Assistant 的 [REST API](https://contributors.home-assistant.io/core/internals/rest-api/)与[模板函数](https://www.home-assistant.io/template-functions/)；栖居不采集米家账号密码。
