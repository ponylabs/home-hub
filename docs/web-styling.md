# 界面样式

参考家庭触控面板的深色三栏：左侧时间、环境与导航，中间示例户型/主内容，右侧设备与 AI。参考图中的影片、人物、真实天气与住宅数据没有复制。

## 组件与主题

基础交互使用 [Mantine](https://mantine.dev/) 的 Card、NavLink、Switch、Slider、Modal、Drawer、Select、Tabs、表单和通知。主题在 [theme.ts](../src/theme.ts)，布局在 [styles.css](../src/styles.css)。不另造一套基础控件。图标统一采用 Lucide。

近黑绿背景、深绿面板、薄荷绿操作状态、暖黄灯光；字体为 Avenir Next / 苹方 / 微软雅黑本地回退，无远端字体请求。状态不只靠颜色，模拟、离线和待确认均有文字。形状语义见[形状规范](ui-radius.md)。

户型使用本地 SVG，热点复用 Mantine 按钮与提示；空间坐标为固定示例，状态来自设备快照。灯光阴影反映房间在线灯状态。不属于示例户型的房间通过导航访问。

## 响应式与交互

宽屏为三栏，1000px 以下主内容和右侧纵排，680px 以下导航转为横向滚动栏。最低验收宽度 360px。保持主要操作可达，不用全页裁切隐藏溢出。

滑块有可访问名称，Mantine 负责弹层焦点与 Escape。设备以服务端回读为准，发送时禁用对应控件。失败提示保留，旧数据继续显示；对话失败保留草稿。短 CSS 状态过渡遵守 reduced-motion。
